# DemoChat - Быстрый мессенджер

Минималистичный мессенджер с регистрацией по номеру телефона. Поддерживает только текстовые сообщения.

## Структура проекта

```
demochat/
├── app.py                 # Flask сервер с API
├── templates/
│   └── index.html         # Главная страница сайта
├── static/
│   └── downloads/         # Папка для файлов приложений
├── requirements.txt       # Зависимости Python
└── README.md             # Этот файл
```

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите сервер:
```bash
python app.py
```

3. Откройте в браузере: http://127.0.0.1:5000

## API Endpoints

- `POST /api/register` - Регистрация нового пользователя
- `POST /api/login` - Вход в аккаунт
- `POST /api/send` - Отправка сообщения (требуется авторизация)
- `GET /api/messages` - Получение сообщений (требуется авторизация)
- `GET /api/users/search?q=` - Поиск пользователей
- `GET /api/status` - Статус сервера
- `GET /download/<filename>` - Скачивание файлов приложений

## Важные замечания

⚠️ **Перед запуском удалите старый `demochat.db` если он существует!**

Проект находится на ранней стадии разработки:
- Поддерживаются только текстовые сообщения
- Нет поддержки голосовых/видео сообщений
- Нет отправки фото и видео

## Безопасность

- HSTS заголовки
- CSP политика
- Защита от brute-force (IP lockout)
- Хеширование паролей (PBKDF2-SHA256)
- Автоматическая очистка старых сообщений (30 дней)

## Лицензия

Проект является неофициальным и находится в стадии разработки. Использование на свой страх и риск.
