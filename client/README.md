# DemoChat Client

Красивый GUI клиент для DemoChat в стиле Telegram.

## Требования

- Python 3.8+
- customtkinter
- requests

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

1. Убедитесь, что сервер запущен (`python app.py`)
2. Запустите клиент:

```bash
python client/client.py
```

## Возможности

✅ **Авторизация и регистрация**
- Красивое окно входа
- Валидация данных
- Проверка подключения к серверу

✅ **Чат**
- Поиск пользователей
- История переписки
- Автообновление сообщений (polling)
- Группировка по датам
- Пузыри сообщений как в Telegram

✅ **Дизайн**
- Тёмная тема
- Адаптивный интерфейс
- Плавные анимации
- Современный UI

## Настройка сервера

По умолчанию клиент подключается к `http://127.0.0.1:5000`

Для изменения отредактируйте строку в начале `client.py`:
```python
SERVER_URL = "http://127.0.0.1:5000"  # Измените на свой адрес
```
